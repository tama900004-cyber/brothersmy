# SmartCane — مشروع محاكاة Glide في Webots

**مهم:** دي محاكاة حركة ثلاثية الأبعاد وليست جهاز آمن لاستخدام المكفوفين.

## التشغيل
1. نزّل Webots R2025a أو أحدث.
2. افتح `worlds/smart_cane_demo.wbt`.
3. اضغط ▶ Run — حتشوف الروبوت يتحرك تلقائياً باتجاه العلامات.
4. أضغط على نافذة 3D قبل مفاتيح التحكم.

## المفاتيح
P: وقوف/مشي افتراضي — B: طوارئ — C: إلغاء الطوارئ — M: يدوي/تلقائي —
السهم يمين/يسار للتحكم اليدوي — F: فشل حساس — R: إعادة البداية.

## الموجود الآن
- مجسم بعجلتين وهاتف وكاميرا.
- خريطة 3D بعوائق.
- توجيه نحو نقاط محفوظة مع توقف برمجي عند الخطر.
- أكواد Python واختبارات لوحدة الملاحة.

## غير الموجود
- لا يوجد AI حقيقي يحلل فيديو الكاميرا.
- لا يوجد اتصال فعلي بـ OpenBot أو ESP32.
- الفرملة والتوجيه **حركة افتراضية فقط**، وليس فيزياء فرامل حقيقية.
- لا يُستخدم مع أشخاص حتى يتم بناء واختبار نظام السلامة فعلياً.
